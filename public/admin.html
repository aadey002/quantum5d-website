How to export from LinkedIn
Option A — Post Analytics page:
LinkedIn profile → click "Show all analytics" on any post → scroll down → "Export" button (top right) → download CSV.

Option B — Creator Analytics:
LinkedIn → Me → Analytics → Content → "Export" (top right).

Expected columns: The CSV should contain columns for post content/title, impressions, clicks/reactions/comments. The importer auto-detects common LinkedIn CSV formats.
